# mediafire_folder_downloader

first update and upgrade the packages by typing Termux : apt update && apt upgrade -y    For Linux Type sudo apt update && sudo apt upgrade -y

then install git Termux : apt install git -y    For Linux Type sudo apt install git -y

then clone the repo by typing git clone https://github.com/mehmoodkhanzafarkhel-56/mediafire_folder_downloader

after that get into the directory by typing cd ./mediafire_folder_downloader

then type ls 

now you have two main files one is req.sh and 2nd is tool_maker.sh

now run the file by typing bash req.sh && tool_maker.sh

this will install all the required package and will also make the downloader program

then go to the directoy where you want to save the file for first type termux-setup-storage then cd storage/downloads

this will download the files in download folder

usage:- python ~/mf_folder.py "https://www.mediafire.com/folder/XXXXXXXXX/Your_Folder"
